# 월간 동향 대시보드

경제·정책, 부동산, 자동차, 항공우주·방산, AI, 휴머노이드·로봇, 2차전지, 에너지·ESG의 8개 분야를 공개하는 한국어 웹 대시보드. 제공보고서의 항목을 임의의 개수 제한으로 줄이지 않습니다.

예정 공개 주소: **https://cblancere-stack.github.io/monthly-trend-dashboard/**

## 처음 한 번만 설정하기

1. 압축을 풀고 안의 파일·폴더를 저장소 **Add file → Upload files** 화면에 끌어다 놓습니다. 폴더 자체가 아니라 `index.html`이 저장소 최상단에 있어야 합니다.
2. `.github/workflows`도 반드시 올립니다. Windows 탐색기에서 보이지 않으면 **보기 → 표시 → 숨긴 항목**을 켜세요. 브라우저 업로드가 실패하면 GitHub Desktop으로 저장소를 열고 파일 복사 → Commit → Push 하세요.
3. **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
4. **Actions → Deploy dashboard to GitHub Pages → Run workflow**를 실행합니다.
5. 성공하면 위 공개 주소에 접속합니다. Pages 설정 전에는 배포가 실패할 수 있습니다.

## 뉴스까지 자동 갱신하려면

Google AI Studio에서 발급한 Gemini API 키를 아래 위치에 직접 등록하세요. 키를 대화나 공개 저장소에 적지 않습니다.

**Settings → Secrets and variables → Actions → Secrets → New repository secret**

| 이름 | 값 |
| --- | --- |
| `GEMINI_API_KEY` | Google AI Studio API 키 |

모델 기본값은 `gemini-flash-latest`입니다. 지원하지 않는 계정이면 **Variables**에 `GEMINI_MODEL`로 Google Search grounding을 지원하는 사용 가능한 모델 ID를 지정하세요. API·검색 사용은 계정별 한도·별도 과금이 적용될 수 있으며 ChatGPT 구독과 별개입니다.

**Actions → Collect and publish monthly report → Run workflow**, `month`에 `2026-10`을 입력해 실제 수집과 비용을 먼저 확인하세요.

## 갱신 일정

- 매월 말일 한국 시간 오후 11시 45분에 당월 현황을 저장하고, 다음 달 1~3일 오전 9시 17분에 전월 보고서를 수집·검증·배포합니다.
- 월말 저장은 AA처럼 과거 조회가 제한된 지표의 당시 값을 보존하기 위한 절차입니다. 평가 버전이 미확인인 동안에는 저장값이 있어도 증감 비교를 하지 않습니다.
- 발표 지연·실패에 대응해 2·3일 재시도합니다. 수동 실행은 원하는 월을 지정할 수 있습니다.
- 예약 작업은 지연될 수 있습니다. 공개 저장소는 60일 무활동 시 예약 작업이 중지될 수 있으므로 월간 커밋이 생성되는지 확인하세요.
- `data/status.json`에 실행일·키 연결 여부·오류 종류를 기록합니다. 비밀키나 API 응답 원문은 저장하지 않습니다.
- 저장소 Actions 실패 알림을 확인하세요. 소스 수집 실패 시 기존 값은 보존됩니다.

## 자동화 범위와 제약

| 항목 | 수집 방식과 제약 |
| --- | --- |
| 화면·월 선택·필터·PDF 인쇄 | 즉시 사용 가능 |
| KB 매매·전세 변동률 | 해당 월 발간일과 공식 원문 숫자 수집. 페이지 구조 변경 시 보류 |
| 거래량·준공 후 미분양 | Gemini 검색으로 공식 통계를 찾고 별도 PDF/HTML 취득 후 근거 대조. 접근 실패 시 기존 값 유지 |
| 뉴스 4/2/2 | Gemini 키 연결 시 공식 발표 검색. 발표일·원문 발췌·숫자가 대조된 카드만 반영 |
| Arena | 공식 평가 부문·날짜·숫자가 확인될 때 갱신. 전월값 없으면 비교 제외 |
| ROBO·Indxx | 날짜가 확인된 원지수만 허용. ETF/CFD 가격 대체 금지. 라이선스/API·안정적인 과거값 경로 연결 전 빈칸이 남을 수 있음 |
| Artificial Analysis 비용 | 미검증 시장 평균 시리즈 종료. 공개 표의 **GPT-6.1 Sol (max) 과제당 비용**을 별도 수집. 평가 버전·과거값 미확인으로 증감 비교 제외 |
| ROBO 팩트시트 | 공식 PDF의 기준일과 **Price Return 최근 3개월 수익률** 수집. 원지수 포인트·전월 수익률과 구분 |
| 자동차·수출·배터리 | 산업부 제목 검색과 검토된 원문 링크에서 해당 월 자료를 발견하면 공식 발표일·실적월·수치 확인. 오래된 보고서는 수동 원문 경로 필요 |
| 통합 SMP | 전력거래소 월별 표에서 지역·연도·월을 고정해 수집. 가중평균 SMP로 대체하지 않음 |
| 방산 수주잔고·IFR 판매량 | 검토한 분기·연간 최신값 유지. 이번 버전에는 새 공시·연간 통계 자동 파서 미연결 |

모든 지표가 완전 자동화됐다고 가정하지 않습니다. 수집 실패 시 해당 기준월의 이전 값, 미확인 값은 ‘확인 대기’를 표시합니다. 2026년 9월 원본 스냅샷을 보존하며, 10월은 **10월 28일 검토 기준 잠정본**입니다. 10월 말 확정본이 아닙니다.

생성형 AI의 문맥 해석은 완벽하지 않습니다. 발췌·숫자 대조는 근거의 존재를 검증하며 모든 해석의 정확성을 보증하지 않습니다. 자동 뉴스는 ‘자동 작성 · 원문 대조 필요’로 표시합니다. 중요한 내용은 원문을 검토하세요.

## 운영 원칙

- 보고서 월은 발표 기준, 실적 집계월은 별도 표시합니다.
- 월간 변동률 `%`와 변동률 차이 `%p`를 구분합니다.
- 같은 기관·범위·단위·수익률 유형·평가 버전을 유지합니다.
- 반올림 증감률로 전월값을 역산하지 않습니다.
- 기업의 계획·목표와 실제 생산·납품 실적을 구분합니다.
- 기존 뉴스는 자동 교체하지 않고 부족한 수만 채웁니다. 정정은 해당 월 JSON과 Git 이력에 남깁니다.
- 자료의 외부 재배포·상업 이용 조건을 기관별로 확인하고 원문 출처를 유지하세요.

## 개발·검증

Python 3.12 이상에서 실행:

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/update_report.py --month 2026-10 --check-only
```

`--check-only`는 파일을 덮어쓰지 않습니다. 키가 없으면 KB·산업부·KPX·ROBO 공식 PDF·AA 공개 표의 직접 수집만 시도합니다. 화면은 정적 서버 또는 Pages에서 확인하세요. `index.html`을 파일로 직접 열면 JSON 로딩이 차단될 수 있습니다.

화면·필터와 파서 테스트는 로컬에서 확인하고, `Check direct data connections` 워크플로로 GitHub 환경의 실시간 접속 결과를 별도로 확인합니다. 제작 환경에서는 외부 사이트 직접 접속이 제한됩니다. Gemini 검색 API는 키 연결 후 별도 검증이 필요합니다.

| 경로 | 용도 |
| --- | --- |
| `index.html`, `assets/` | 공개 화면 |
| `data/index.json` | 월별 목록 |
| `data/reports/YYYY-MM.json` | 수치·뉴스·출처 |
| `data/sectors.json` | 분야명·뉴스 한도·공식 출처 허용 목록 |
| `scripts/update_report.py` | 수집·근거 대조 |
| `scripts/direct_sources.py` | 공식 표·PDF 전용 수집기 |
| `tests/test_data.py` | 날짜·잘못된 숫자·출처 변경 방지 테스트 |
| `.github/workflows/` | 배포·월간 갱신 |

공개 사이트에는 화면과 데이터만 배포합니다. 키는 GitHub Actions Secrets에만 저장합니다.

`scripts/seed_initial.py`는 초기 스냅샷을 다시 만들 때만 수동 실행하며 예약 작업에서 실행하지 않습니다.

## 지표 변경 이력

- 기존 미검증 AA 평균비용 `aa_cost`를 종료하고 `aa_cost_sol`을 별도 시계열로 추가했습니다. 과거 예시 수치와 연결하지 않습니다.
- ROBO 포인트 `robo`와 3개월 수익률 `robo_return`은 다른 지표입니다. 전자는 연결 대기, 후자는 공식 팩트시트를 인용합니다.
- 분기·연간 지표를 전월 대비로 계산하지 않습니다. 단일 기업·모델 수치는 해당 범위를 카드에 명시합니다.
- 새 분야 추가: `data/sectors.json`에 정의하고, `METRIC_HOSTS`·전용 파서·검증된 보고서 값을 함께 추가합니다. PPT 숫자를 출처 대조 없이 자동 등록하지 않습니다.

## 제공보고서 전체 복원과 첫 화면

- 첫 화면은 제공 PPT 3쪽의 5개 섹터 개요를 바탕으로 구성합니다. ‘전체 보기’ 대신 ‘섹터별 주요 내용 요약’에서 세부 섹터로 이동합니다.
- 제공보고서 보존본: 대표 지표 36개, 뉴스·현안 58개, 정부정책 8개, 일정 20개. 경제·사회·규제·정치에는 지표 10개·현안 18개·정부정책 4개가 있습니다.
- 45쪽의 텍스트와 사용된 원본 그림을 함께 보존합니다. 뉴스·동향·신기술 항목을 각각 카드로 나누어 원본 목차의 ‘이슈 수’ 표기와 카드 수가 다를 수 있습니다.
- 제공자료는 원본 기재값이며 공식 통계의 독립 검증 완료를 뜻하지 않습니다. 기존 예시 수치와 지표 정의 오류 가능성은 주석으로 남기고 삭제하지 않습니다.
- `data/provided-report.json`과 `assets/provided-original/`은 제공자료 보존본입니다. 자동 수집기는 이 파일을 덮어쓰지 않습니다. 공식 조사본은 `data/reports/`에서 별도 운영합니다.
- 재추출: `python scripts/import_provided_report.py /absolute/path/to/source.pptx`. 수작업으로 대조한 3쪽 요약은 `data/provided-overview.json`에 있습니다. `lxml`이 필요합니다.
- 자동 뉴스 수집의 섹터별 상한도 제거했습니다. 출처·발표일·근거 대조와 중복 확인은 유지합니다.
